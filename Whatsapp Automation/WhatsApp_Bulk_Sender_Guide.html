System Overview — How It Works

The system reads phone numbers from your CSV file, opens WhatsApp Web in Chrome, and sends your message to each number — one at a time — with random delays for safety.

📄 CSV File (Phone Numbers)
↓
🐍 Python Script
↓
🌐 Chrome + Selenium Automation
↓
💬 WhatsApp Web Opens Each Chat
↓
✅ Message Sent — Next Number
💡

Key Concept: The script uses a direct link format — https://web.whatsapp.com/send?phone=NUMBER&text=MESSAGE — to open a pre-filled chat. Then it automatically clicks Send. It processes numbers one by one with a random 25–60 second wait between each.

Software Installation

Step A — Install Python

Download Python from python.org (version 3.8 or higher). During installation, check "Add Python to PATH".

Verify it works by opening Terminal / Command Prompt and typing:

python --version # Should print: Python 3.x.x

Step B — Install Google Chrome

Download and install Google Chrome from google.com/chrome. The script automatically downloads the matching ChromeDriver — no manual download needed.

Step C — Install Python Libraries

Open Terminal (Mac/Linux) or Command Prompt (Windows) and run:

pip install selenium pandas webdriver-manager
✅

webdriver-manager automatically downloads and manages the correct ChromeDriver for your Chrome version. You never have to manually match versions again.

How the Sending Logic Works

For each phone number, the script builds a special WhatsApp Web URL that pre-fills the chat box with your message:

# The URL format: https://web.whatsapp.com/send?phone=923001234567&text=Your+message+here # Python builds this automatically: encoded_msg = urllib.parse.quote(MESSAGE) url = f"https://web.whatsapp.com/send?phone={phone}&text={encoded_msg}"

Chrome opens this URL → WhatsApp Web loads the chat with the message pre-filled → Selenium finds the Send button → Clicks it → Waits a random delay → Moves to next number.

💡

The message is URL-encoded (spaces become +, special characters are safely escaped) so it works correctly in the link.

Safety Settings — Avoiding Account Restrictions

WhatsApp monitors for unusual activity. These safety measures are built into the script:

Safety FeatureWhy It Matters
Random delays (25–60 sec) Mimics human behavior. Fixed delays look robotic; random delays look natural.
Session limit (50/day) Sending too many messages too fast triggers WhatsApp's spam detection.
Auto-skip failed numbers If a chat fails to open, the script moves on instead of retrying repeatedly.
Progress saved to files If the script is stopped, you know exactly which numbers were sent.
⚠️

Recommended Daily Limits: Stay under 150–200 messages per day. Send to people who may recognize your number. Avoid sending to completely cold/unknown contacts in bulk — this is what gets accounts banned.

🚫

WhatsApp's Terms: Bulk messaging technically violates WhatsApp's Terms of Service. Use this tool responsibly — for people you have prior contact with. Anthropic does not endorse spamming.

Output Files — Progress Tracking

After each session, the script saves two log files in your project folder:

FileContents
sent_20260309_103215.txtAll numbers that were successfully messaged
failed_20260309_103215.txtNumbers that failed (can retry next session)

The timestamp in the filename (e.g., 20260309_103215) ensures files from different sessions don't overwrite each other.

💡

To retry failed numbers: rename failed_TIMESTAMP.txt to contacts.csv and add a phone header row at the top. Then run the script again.

Troubleshooting — Common Problems & Fixes
Problem Cause Fix
❌ ChromeDriver version mismatch Old ChromeDriver cached Run: pip install --upgrade webdriver-manager — it auto-fetches the correct version
❌ QR code not loading Slow internet or WhatsApp server Increase QR_SCAN_WAIT = 90 in the script. Also try a different network.
❌ Message not sending Send button not found Increase PAGE_LOAD_WAIT = 35. WhatsApp Web may be loading slowly.
❌ Script stops unexpectedly Chrome crashed or disconnected Restart the script. Use the failed_*.txt to know where to resume.
❌ "Module not found" error Libraries not installed Run: pip install selenium pandas webdriver-manager
❌ CSV column not found Wrong column name Make sure your CSV has a column named exactly phone (lowercase)
❌ WhatsApp asks to scan again Chrome profile deleted Don't delete the chrome_profile folder — it stores your login session
❌ "Invalid number" in WhatsApp Wrong number format Make sure numbers have country code, no +, no spaces. Pakistan: 923001234567

⚠️

Why delays are essential: WhatsApp's systems analyze message frequency patterns. Sending 50 messages in 5 minutes is an obvious bot pattern. Sending 50 messages over 45 minutes with varying gaps looks human. The 25–60 second random delay is carefully chosen for this reason.

💡

Recommended Strategy: Run one session of 50 messages in the morning, one in the afternoon. Keep MAX_MESSAGES_PER_SESSION = 50 and stay well under 150/day, especially with a newer WhatsApp account.
